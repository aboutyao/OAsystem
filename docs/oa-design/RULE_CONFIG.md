# 企业级 OA 规则配置清单

## 1. 文档定位

本文档定义 OA 系统中不应写死在代码里的业务规则和系统配置项，用于指导规则配置中心、系统参数、数据字典和测试用例设计。

原则：

- 企业制度会变的，必须配置化。
- 不同部门可能不同的，优先配置化。
- 影响流程走向的，必须配置化并版本化。
- 影响历史统计口径的，必须配置化并保留版本。
- 高风险规则修改必须写审计日志。

## 2. 配置类型

| 类型 | 说明 | 是否版本化 |
| --- | --- | --- |
| 系统参数 | 密码、会话、文件大小等 | 可选 |
| 数据字典 | 类型、分类、状态等枚举 | 可选 |
| 业务规则 | 金额、时间、附件、审批阈值 | 必须 |
| 流程规则 | 审批人、超时、驳回、兜底 | 必须 |
| 报表口径 | 统计时间、部门口径、是否包含作废 | 必须 |
| 安全策略 | 密码复杂度、登录锁定、IP 白名单 | 可选 |

## 17. 规则发布流程

```text
编辑规则草稿
  ↓
填写变更原因
  ↓
规则模拟测试
  ↓
冲突检测
  ↓
发布规则版本
  ↓
新业务使用新版本
  ↓
历史业务保留旧版本
```

## 18. 规则验收

必须验证：

- 金额规则影响流程分支。
- 工作日历影响请假时长。
- 节假日、调休日计算正确。
- 规则版本不影响历史单据。
- 规则发布有审计日志。
- 规则冲突可提示。
- 规则模拟结果可解释。
