# 企业级 OA 系统测试计划

## 1. 文档定位

本文档定义 OA 系统最终版本的测试范围、测试类型、关键用例和验收标准，用于保证系统在完整功能、复杂流程、权限安全、规则配置、响应式体验和运维可靠性方面达到上线要求。

## 2. 测试目标

- 验证最终版本全部功能可用。
- 验证权限控制无越权。
- 验证流程引擎和业务规则正确。
- 验证数据快照、版本和历史追溯正确。
- 验证附件、导出、敏感字段安全。
- 验证 1000+ 用户规模下性能可接受。
- 验证 PC 和移动端关键路径可用。
- 验证备份、恢复、日志和异常定位可用。

## 3. 测试类型

| 类型 | 说明 |
| --- | --- |
| 单元测试 | Service、规则计算、状态机、工具类 |
| 接口测试 | API 参数、返回、错误码、权限 |
| 功能测试 | 各业务模块功能 |
| 权限测试 | 菜单、按钮、数据、字段、附件、审批 |
| 流程测试 | Flowable 流程、会签、或签、转交、加签 |
| 规则测试 | 金额、时间、编号、超时、报表口径 |
| 安全测试 | 登录、越权、附件、导出、XSS、SQL 注入 |
| 性能测试 | 登录、列表、待办、审批、导出、附件 |
| 响应式测试 | PC、平板、手机浏览器 |
| 恢复测试 | 数据库备份、附件备份、恢复演练 |
| 用户验收测试 | 业务人员按真实场景验收 |

## 4. 测试环境

建议环境：

- 开发环境
- 测试环境
- 预发布环境
- 生产环境

测试环境应尽量接近生产：

- 独立数据库
- 独立 Redis
- 独立文件目录
- 与生产接近的 Nginx 配置
- 模拟 1000+ 用户基础数据

## 5. 基础功能测试

### 5.1 认证

用例：

- 正确账号密码可登录。
- 错误密码登录失败。
- 连续失败达到阈值后账号锁定。
- 锁定时间后可重新登录。
- 用户可修改密码。
- 管理员可重置密码。
- 离职和停用用户不可登录。
- 未登录访问接口返回 `UNAUTHORIZED`。

### 5.2 组织人员

用例：

- 可新增、编辑、停用部门。
- 可设置部门负责人。
- 可新增、编辑、停用用户。
- 可维护岗位、职级、直属上级。
- 用户可设置主部门和兼职部门。
- 用户导入时错误行可提示原因。
- 离职用户的待办、资产、权限可处理。
- 组织变更日志可查询。

### 5.3 字典与系统参数

用例：

- 字典类型可新增和停用。
- 字典项可排序。
- 停用字典项不影响历史数据展示。
- 系统参数修改后生效。
- 高危参数修改写入审计日志。

## 6. 权限测试

### 6.1 菜单和按钮

用例：

- 普通员工不能看到系统管理菜单。
- 无新增权限时不显示新增按钮。
- 直接访问无权限路由被拒绝。
- 直接调用无权限接口返回 `FORBIDDEN`。

### 6.2 数据权限

用例：

- 普通员工只能查看本人数据。
- 部门负责人可查看本部门及下级数据。
- 财务只可查看授权范围内报销数据。
- 行政只可查看授权范围内行政数据。
- 审计只读，不可修改业务数据。
- 导出结果受数据权限控制。

### 6.3 字段和附件权限

用例：

- 普通审批人查看报销时收款账户脱敏。
- 财务可编辑实付金额和付款状态。
- 无附件下载权限时不能下载附件。
- 合同附件下载写入日志。
- 敏感附件不可通过公开 URL 访问。

### 6.4 审批权限

用例：

- 非当前审批人不能审批。
- 当前审批人可通过和驳回。
- 转交后原审批人不能审批。
- 流程管理员干预写审计日志。

## 7. 流程测试

### 7.1 基础流程

用例：

- 保存草稿不启动流程。
- 提交后生成流程实例。
- 提交后生成首个待办。
- 审批通过后流转下一节点。
- 流程完成后单据状态为已通过。
- 流程时间轴显示准确。
- 流程图高亮准确。

### 7.2 条件分支

用例：

- 报销金额小于等于 5000 走财务复核。
- 报销金额大于 5000 追加部门负责人。
- 报销金额大于 10000 追加总经理。
- 请假超过 3 天追加领导审批。
- 合同金额超过阈值追加财务会签。

### 7.3 会签和或签

用例：

- 会签全部同意后进入下一节点。
- 会签任一驳回后按配置驳回。
- 或签任一同意后进入下一节点。
- 或签其他任务被取消或跳过。

### 7.4 转交、加签、委托

用例：

- 当前审批人可转交。
- 转交后新审批人可处理。
- 加签后加签人收到待办。
- 委托期间任务分配给被委托人。
- 委托过期后恢复本人处理。

### 7.5 异常流程

用例：

- 审批人为空转流程管理员。
- 审批人离职转流程管理员。
- 审批人等于发起人按规则跳过或上浮。
- 撤回和审批同时发生时只有一个成功。
- 重复点击审批不会重复流转。

## 8. 规则测试

### 8.1 金额规则

用例：

- 修改金额阈值后新单据走新流程。
- 旧单据仍按旧规则展示。
- 规则冲突可提示。
- 规则模拟结果与实际流程一致。

### 8.2 工作时间

用例：

- 请假时长扣除午休。
- 请假时长跳过节假日。
- 调休日按工作日计算。
- 部门差异工作时间生效。

### 8.3 编号规则

用例：

- 单据编号按前缀生成。
- 流水号不重复。
- 日期变化后编号正确。
- 并发创建时编号不重复。

### 8.4 报表口径

用例：

- 按发起时间统计正确。
- 按审批通过时间统计正确。
- 当前部门和申请时部门口径差异正确。
- 驳回、撤回、作废是否计入按配置生效。

## 9. 业务模块测试

### 9.1 请假

- 请假时间不能结束早于开始。
- 病假按规则要求附件。
- 超过阈值追加审批。
- 请假通过后可统计。
- 销假和延期规则正确。

### 9.2 报销

- 报销金额必须大于 0。
- 明细合计等于总金额。
- 发票附件规则生效。
- 财务可填写实付金额。
- 付款状态可更新。
- 报销单可打印。

### 9.3 用章

- 用章文件必填规则生效。
- 重要印章追加审批。
- 外带用章可登记归还。
- 用章记录可追溯。

### 9.4 采购

- 采购明细至少一项。
- 金额达到阈值追加审批。
- 比价附件规则生效。
- 到货确认和验收状态正确。

### 9.5 合同

- 合同附件必填。
- 高金额合同追加审批。
- 合同签署、履行、到期状态正确。
- 到期提醒生成。
- 合同附件版本可追溯。

### 9.6 会议、资产、办公用品

- 会议室时间冲突不可预约。
- 资产领用、归还、维修、报废记录正确。
- 离职时资产归还检查。
- 办公用品出库不能导致负库存。
- 库存预警正确。

## 10. 导入导出测试

用例：

- 导入前可预校验。
- 错误行提示明确。
- 可只导入正确行。
- 导入结果生成批次。
- 导出受数据权限控制。
- 大数据导出生成异步任务。
- 导出文件下载写日志。

## 11. 安全测试

用例：

- SQL 注入拦截。
- XSS 内容过滤或安全输出。
- 未登录不能访问接口。
- 越权访问返回 `FORBIDDEN`。
- 附件直链不可访问。
- 敏感字段脱敏。
- 高危操作二次确认并审计。
- 普通管理员不能删除审计日志。

## 12. 性能测试

建议数据量：

- 用户：1000-5000。
- 部门：100-300。
- 单据：10 万级。
- 消息：50 万级。
- 日志：100 万级。

重点接口：

- 登录。
- 用户列表。
- 待办列表。
- 审批详情。
- 审批通过。
- 流程时间轴。
- 报销列表。
- 合同列表。
- 附件下载。
- 报表查询。

目标：

- 常规列表 500ms-1000ms 内优先。
- 待办查询稳定。
- 审批动作不重复提交。
- 大导出不阻塞业务接口。

## 13. 响应式测试

设备宽度：

```text
>= 1200px：桌面端
768px - 1199px：平板端
< 768px：手机端
```

移动端必测：

- 登录。
- 工作台。
- 我的待办。
- 审批详情。
- 审批通过和驳回。
- 公告查看。
- 消息查看。
- 附件查看。
- 简单申请。

## 14. 备份恢复测试

用例：

- 数据库备份任务成功。
- 附件备份任务成功。
- 备份失败可告警。
- 可从备份恢复数据库。
- 可从备份恢复附件。
- 恢复后流程、附件、用户权限正常。

## 15. 验收出口

上线前必须满足：

- P0/P1 缺陷清零。
- 权限越权类缺陷清零。
- 数据丢失类缺陷清零。
- 流程状态错乱类缺陷清零。
- 附件泄露类缺陷清零。
- 核心路径通过用户验收。
- 备份恢复演练通过。
- 性能测试达到目标。
