# OA 系统 — 内部交付 / 试用版使用指南

> 本指南面向甲方 / PM / 内部测试用户，定义试用范围、初始账号、演示脚本、已知未交付项，以及问题反馈渠道。
> 部署口径见 [DEPLOYMENT_GUIDE.md §20](DEPLOYMENT_GUIDE.md#20-内部交付--试用版部署trial)。

## 1. 试用范围

试用版包含以下模块，全部为真实业务流转，非占位 mock：

| 模块 | 子页 / 能力 |
| --- | --- |
| 登录 / 工作台 | 登录、修改密码、工作台聚合（待办 / 我发起 / 抄送 / 未读 / 异常 / 公告 / 快捷入口） |
| 组织 / 权限 | 部门树、用户管理、角色 / 菜单 / 数据范围 / 临时授权 |
| 流程 | 模板 / 实例 / 异常 / 模拟器、流程图历史节点高亮、转交 / 加签（顺序+并行）/ 委托 / 抄送我的 |
| 申请 | 请假、报销、用章、采购、合同、公告、会议室、资产、办公用品、消息、文件资料库 |
| 系统 | 配置、字典、编号规则、工作日历、导入导出任务 |
| 表单 | 表单模板、版本、字段权限规则、最简版 Designer 预览 |
| 报表 | 工作流效率、待办分布、请假 / 报销 / 合同 / 资产 / 用户 7 子页 |
| 审计 / 运维 | 登录日志、操作日志、在线用户、定时任务日志、异常日志、备份记录 |

试用版的所有写操作（提交 / 审批 / 转交 / 加签 / 资产领用 / 公告发布 / 文件登记 / 消息归档 等）都会写入 `audit_operation_log`，可在【审计中心】可视化查询。

## 2. 演示脚本（端到端，干净环境一次跑通）

> 角色：`admin / SUPER_ADMIN`、`zhangsan / SYSTEM_ADMIN`、`lisi / EMPLOYEE`。
> 在数据库初始化后，仅 `admin` 由 V2 种子写入；`zhangsan` 与 `lisi` 由 admin 在【组织 / 用户】页创建并赋予角色。
> 演示前先用 admin 登录，按 §2.0 准备账号。

### 2.0 准备演示账号（admin）

1. 登录 → 顶部右侧改密 → 设置一个临时密码。
2. 【组织 → 用户】 → 新建：
   - `zhangsan / 张三`，主部门「研发部」，角色 `SYSTEM_ADMIN`。
   - `lisi / 李四`，主部门「研发部」，直接上级 `zhangsan`，角色 `EMPLOYEE`。
3. 【系统 → 工作日历】 → 添加 1 天「调休工作日」、1 天「节假日」（用于 §2.5 报表展示）。

### 2.1 普通员工发起请假（lisi）

1. lisi 登录 → 工作台 → 快捷入口「发起请假」。
2. 选择请假类型「年假」，开始/结束时间均设为当前日期 + 2 小时窗口，提交。
3. 【我发起的】可见状态 `APPROVING`，节点显示「直属上级审批」。
4. 顶部消息中心可见一条新消息（提醒上级审批）。

### 2.2 直属上级审批（zhangsan）

1. zhangsan 登录 → 工作台「我的待办」。
2. 点开 lisi 的请假任务 → 选择「转交给 admin」（演示转交） → 备注「转交给总经理审批」。
3. admin 登录 → 待办 → 同一条任务 → 选择「加签 / 顺序」→ 加签人 zhangsan → 提交。
4. zhangsan 登录 → 待办（看到加签任务）→ 通过 → 系统自动回签到 admin → admin 通过。
5. lisi 登录 → 工作台 → 流程已变为 `APPROVED`。

### 2.3 委托与抄送（admin）

1. admin → 【流程 → 委托】 → 创建：受托人 zhangsan，业务范围 LEAVE，时间窗口为今天-后天。
2. lisi 再发一条「事假」请假申请 → 待办自动到 zhangsan（命中委托）。
3. zhangsan 在审批前先点「抄送」 → 抄送给 admin → admin 在【流程 → 实例 → 抄送我的】可见。
4. admin → 【流程 → 委托】 → 取消刚才的委托。

### 2.4 报销并触发金额阈值（lisi）

1. lisi → 发起报销 → 类别「差旅」→ 添加 2 条明细，合计 6000 → 提交。
2. 流程因金额 ≥ 5000 自动多走一步（部门负责人审批），可在【流程 → 实例 → 时间轴 + 流程图】中看到节点变化。
3. zhangsan 通过 → admin 通过。
4. admin → 【报销 → 详情】→「标记已支付」。

### 2.5 报表查看（admin / zhangsan）

进入【报表】，依次查看：

- 工作流效率：本月发起 / 已完成 / 平均时长。
- 待办分布：仍有待办的任务统计。
- 请假 / 报销 / 合同 / 资产 / 用户：按部门 / 类型 / 状态汇总。

### 2.6 系统配置 + 编号规则（admin）

1. 【系统 → 字典】 → 查看 `LEAVE_TYPE` 等字典；
2. 【系统 → 编号规则】 → 选 `EXPENSE_NO` → 点击「预览」连续生成 3 个，确认编号自增不重复；
3. 【系统 → 工作日历 → 工作日统计】 → 输入区间，验证节假日 / 调休的扣减。

### 2.7 文件资料库 + 公告（admin）

1. 【文件资料库】→ 新建文件夹「试用文档」 → 登记 1 个文件（路径 / 大小可任意）。
2. 【公告】→ 新建「试用启动公告」 → 发布 → 所有用户工作台均能看到「最近公告」。

### 2.8 审计与运维（admin）

1. 【审计 → 操作日志】→ 按业务 `EXPENSE` 过滤 → 应能看到提交 / 通过 / 已支付完整链路。
2. 【运维 → 系统健康】 → 状态 `UP`、近 30 分钟在线用户列表非空。
3. 【运维 → 定时任务日志】、【异常记录】、【备份记录】各能正常分页 + 过滤。

> 步骤 2.1—2.8 全部跑通即视为试用版核心路径通过。预计 30—45 分钟。

## 3. 已知未交付（试用版不在范围）

- 性能压测（1000-5000 并发、10w-100w 单据 / 日志体量）。
- UAT 全量（业务部门按真实场景验收并签字）。
- 数据库 + 附件 + 流程实例的备份恢复演练（界面已就绪，未做端到端真实演练）。
- 用户 / 部门 Excel 批量导入与错误行回执。
- 文件资料库的真正对象存储 + 分片上传 + 病毒扫描。
- 移动端响应式专项（当前以桌面 1280+ 分辨率优先）。
- 报表导出真正异步调度（试用版仅同步小数据导出）。
- 培训手册 / 操作演示视频。

## 4. 反馈与问题分级

请通过约定的反馈渠道（邮件 / 飞书 / Issue）提交问题，按以下分级：

| 级别 | 定义 | 示例 |
| --- | --- | --- |
| P0 | 试用阻塞 | 无法登录、流程不流转、数据丢失、白屏 |
| P1 | 主路径偏差 | 审批通过但单据状态未变、菜单按钮可见但点击 500 |
| P2 | 体验问题 | 界面错位、文字不准确、空状态展示不友好 |
| P3 | 改进建议 | 功能性增强、UI 微调 |

提交时附上：

- 重现步骤 + 期望结果 + 实际结果。
- 用户角色（admin / zhangsan / lisi）与浏览器版本。
- 后端 `/api/audit/operation-logs` 中相关时间段的 `requestId`（页面右下角悬浮可见）。
