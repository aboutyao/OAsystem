# 企业级 OA 流程规则设计

## 1. 文档定位

本文档定义 OA 系统最终版本的流程审批规则，用于指导 Flowable 集成、流程模板配置、规则中心联动、审批页面设计和测试用例编写。

流程设计原则：

- Flowable 负责流程流转、任务生成、历史追踪。
- OA 流程服务层负责权限、表单、规则、消息、审计和展示。
- 业务模块不直接调用 Flowable API。
- 流程模板发布后生成版本，历史流程绑定历史版本。
- 流程可配置，但不做无限低代码平台。

## 2. 通用流程状态

业务单据状态：

```text
DRAFT       草稿
SUBMITTED   已提交
APPROVING   审批中
APPROVED    已通过
REJECTED    已驳回
WITHDRAWN   已撤回
CANCELLED   已作废
ARCHIVED    已归档
TERMINATED  已终止
```

审批任务状态：

```text
PENDING      待处理
APPROVED     已同意
REJECTED     已驳回
TRANSFERRED  已转交
ADDED        已加签
SKIPPED      已跳过
CANCELLED    已取消
TIMEOUT      已超时
```

## 3. 通用审批动作

| 动作 | 说明 | 关键校验 |
| --- | --- | --- |
| 保存草稿 | 保存业务表单，不启动流程 | 创建人本人 |
| 提交 | 启动流程实例，生成首个待办 | 表单校验、规则校验、幂等 |
| 通过 | 当前任务审批通过 | 当前任务处理人 |
| 驳回 | 驳回到发起人或历史节点 | 当前任务处理人、驳回原因必填 |
| 撤回 | 发起人撤回未结束流程 | 发起人、流程未结束 |
| 作废 | 作废业务单据 | 授权人员、高危审计 |
| 转交 | 当前任务转给他人 | 当前任务处理人或流程管理员 |
| 加签 | 增加临时审批人 | 当前任务处理人或流程管理员 |
| 委托 | 指定时间段委托他人处理 | 委托人本人 |
| 催办 | 提醒当前审批人 | 限频 |
| 终止 | 管理员终止异常流程 | 流程管理员、高危审计 |

## 4. 审批人规则

支持审批人来源：

- 指定人员
- 指定角色
- 部门负责人
- 直属上级
- 连续多级上级
- 发起人自选审批人
- 表单字段指定人员
- 流程管理员兜底

异常规则：

- 找不到审批人：转交流程管理员。
- 审批人等于发起人：按模板配置跳过或上浮一级。
- 审批人离职：自动转交流程管理员并生成异常提醒。
- 多人审批全部无效：流程进入异常状态，等待管理员处理。

## 5. 通用流程模板

### 5.1 标准单据流程

适用：请假、用章、普通采购、普通合同。

```text
发起人提交
  ↓
直属上级审批
  ↓
部门负责人审批
  ↓
业务归口审批（人事/行政/财务/合同管理员）
  ↓
归档完成
```

### 5.2 金额分支流程

适用：报销、采购、合同、付款类单据。

```text
发起人提交
  ↓
直属上级审批
  ↓
金额条件判断
  ├── 小额：业务归口审批
  ├── 中额：部门负责人 → 业务归口审批
  └── 大额：部门负责人 → 分管领导/总经理 → 业务归口审批
  ↓
归档完成
```

### 5.3 会签流程

适用：采购、合同、制度文件。

```text
发起人提交
  ↓
直属上级审批
  ↓
财务 + 行政 + 合同管理员会签
  ↓
领导审批
  ↓
归档完成
```

会签规则：

- 默认全部同意后节点通过。
- 任一人驳回时，默认整体驳回到发起人。
- 可配置为“驳回后继续等待其他人意见”。

### 5.4 或签流程

适用：同岗位多人均可处理的行政、财务复核。

```text
发起人提交
  ↓
候选审批人组
  ↓
任一人审批通过
  ↓
下一节点
```

或签规则：

- 任一人通过后节点通过。
- 其他未处理任务自动取消或标记跳过。
- 任一人驳回时按模板规则处理。

## 6. 业务流程规则

### 6.1 请假流程

变量：

- `leaveType`
- `durationHours`
- `durationDays`
- `deptId`
- `starterId`

默认流程：

```text
员工提交
  ↓
直属上级审批
  ↓
请假天数判断
  ├── <= 1 天：人事备案
  ├── > 1 且 <= 3 天：部门负责人审批 → 人事备案
  └── > 3 天：部门负责人审批 → 分管领导审批 → 人事备案
  ↓
完成
```

规则：

- 请假时间根据工作日历计算。
- 病假可配置是否必须上传证明。
- 请假超过阈值可要求交接说明。
- 请假通过后可触发审批代理提醒。

### 6.2 报销流程

变量：

- `amount`
- `expenseType`
- `deptId`
- `hasInvoice`

默认流程：

```text
员工提交
  ↓
直属上级审批
  ↓
金额判断
  ├── <= 5000：财务复核
  ├── > 5000 且 <= 10000：部门负责人审批 → 财务复核
  └── > 10000：部门负责人审批 → 总经理审批 → 财务复核
  ↓
财务付款
  ↓
完成
```

规则：

- 报销金额必须大于 0。
- 报销明细合计必须等于总金额。
- 指定费用类型必须上传发票。
- 财务复核节点可填写实付金额和付款状态。

### 6.3 用章流程

变量：

- `sealType`
- `outFlag`
- `fileCount`

默认流程：

```text
员工提交
  ↓
直属上级审批
  ↓
行政审批
  ↓
重要印章判断
  ├── 普通印章：用章登记
  └── 重要印章：部门负责人/领导审批 → 用章登记
  ↓
完成
```

规则：

- 用章必须填写文件名称和用途。
- 外带用章必须登记归还。
- 重要印章必须上传用章文件附件。

### 6.4 采购流程

变量：

- `amount`
- `purchaseType`
- `supplierName`
- `needCompare`

默认流程：

```text
员工提交
  ↓
直属上级审批
  ↓
金额判断
  ├── 小额：行政/采购复核
  ├── 中额：部门负责人 → 行政/采购复核
  └── 大额：部门负责人 → 财务会签 → 总经理审批 → 行政/采购复核
  ↓
到货确认
  ↓
验收
  ↓
完成
```

规则：

- 采购明细至少一项。
- 达到比价阈值必须上传比价附件。
- 到货确认和验收不是同一个状态。
- 可配置是否转固定资产。

### 6.5 合同流程

变量：

- `amount`
- `contractType`
- `counterparty`
- `endDate`

默认流程：

```text
员工提交
  ↓
直属上级审批
  ↓
合同管理员复核
  ↓
金额判断
  ├── 普通合同：部门负责人审批
  └── 高金额合同：部门负责人审批 → 财务会签 → 总经理审批
  ↓
合同归档
  ↓
履行中
```

规则：

- 合同附件必须上传。
- 高金额合同追加领导审批。
- 到期提醒按规则中心配置。
- 补充协议走合同变更流程。

## 7. 驳回与撤回规则

驳回方式：

- 驳回到发起人。
- 驳回到指定历史节点。
- 驳回后重新提交从原驳回节点继续。
- 驳回后重新提交从头开始。

默认建议：

- 普通业务：驳回到发起人，重新提交从头开始。
- 合同、采购等复杂流程：允许驳回到指定历史节点。

撤回规则：

- 发起人可在流程未结束前撤回。
- 当前节点已审批完成但流程未结束，是否允许撤回由模板配置。
- 已完成、已终止、已作废流程不可撤回。
- 撤回必须写流程记录。

## 8. 超时与催办规则

默认规则：

- 普通审批节点：24 小时超时。
- 财务复核节点：48 小时超时。
- 合同复核节点：48 小时超时。
- 总经理审批节点：72 小时超时。

提醒规则：

- 超时前 2 小时提醒审批人。
- 超时后提醒审批人。
- 超时 2 次后提醒直属上级或流程管理员。
- 催办 2 小时内限 1 次。

所有提醒和催办必须写入流程记录。

## 9. 流程进度展示

进度展示内容：

- 当前节点
- 当前处理人
- 已处理节点
- 未开始节点
- 审批意见
- 附件
- 超时状态
- 催办记录
- 流程版本
- 规则命中说明

PC 端：

- 流程图高亮 + 时间轴。

移动端：

- 时间轴优先。

## 10. 流程版本规则

- 流程模板草稿不影响已发布版本。
- 发布流程生成新版本。
- 新发起单据使用最新启用版本。
- 已发起单据继续使用原版本。
- 历史版本不可物理删除。
- 停用版本不影响历史查看。

## 11. 流程测试用例重点

必须覆盖：

- 条件分支。
- 会签全部通过。
- 会签驳回。
- 或签任一通过。
- 转交后原审批人不可审批。
- 加签后任务顺序正确。
- 委托期间任务转给被委托人。
- 审批人为空兜底。
- 审批人离职兜底。
- 审批人等于发起人。
- 撤回和审批并发。
- 重复点击审批。
- 流程版本隔离。
- 超时提醒。
- 催办限频。
